# 「强龙出现」方案研究：它宣称了什么、数据怎么说、以及一份聚宽脚本

> 本文是 [`README.md`](README.md) 的中文对照版。英文版是准本，两份同步更新；数字完全一致。
> 文中第一次出现的金融/统计词汇会在括号里用白话解释，文末另有完整术语表。

资料来源：仓库根目录的 `强龙出现运营方案.pptx`（41 页，18.7 MB，未提交到 git）。这是一个闭源看盘指标
「强龙出现」的销售与运营方案，出自一个做「龙头战法」（专挑一波行情里涨得最猛、最先启动的那只股票去追）的团队。

状态：仅供研究，属于 MVP、未在聚宽上验证。这里没有任何东西可以直接用于实盘。

## 先看这里：十个最常见的词

| 词 | 白话解释 |
|---|---|
| 涨停 / 跌停 | 交易所规定的单日最大涨幅 / 跌幅。主板 10%，创业板和科创板 20%，北交所 30%，ST 股 5%。 |
| 一字涨停（一字板） | 开盘就在涨停价，一整天都没打开过（开盘价 = 最高价 = 最低价 = 收盘价）。想买的人排队，几乎买不到。 |
| 主升浪 | 一波行情里最陡、最赚钱的那一段，常见形态是连续涨停。PPT 只想做这一段。 |
| 均线 MA5 / MA10 / MA20 | 最近 5 / 10 / 20 个交易日收盘价的平均值。MA5 > MA10 > MA20 叫「多头排列」，表示短期价格高于长期价格，即处在上涨趋势。 |
| 3 日涨幅（ret3） | 今天收盘价相对 3 个交易日前收盘价涨了多少。 |
| 胜率 | 赚钱的交易占全部交易的比例。 |
| 最大回撤 | 资金曲线从某个高点往下跌得最深的一次幅度，衡量「最惨的时候亏多少」。 |
| 样本内 / 样本外 | 用一段历史数据设计规则（样本内），再用之后没用过的数据检验（样本外）。只有样本外的结果才算数。 |
| 过拟合 | 规则只是「背熟了」过去的数据，在新数据上就失效。 |
| 幸存者偏差 | 只研究今天还活着、还在指数里的股票，会让结果看起来比真实情况好。 |

## 一句话结论

- PPT 里的案例收益是真的，但都是**事后挑出来的**：21 个宣传收益里，19 个能按「起始日前一天收盘 → N 个交易日后收盘」
  复现到 ±10 个百分点以内（16 个误差在 1 个百分点内）。每个区间都恰好从连板启动前开始、在顶部附近结束，
  这只有事后才能做到。另外 3 页的结束日期写错；c06 年份写错，且它的「两波 110%」无法复现。
- 指标可以用两条规则从截图里近似出来（红柱 ≈ 主升浪进行中，绿柱 ≈ 主升浪结束）：
  能找出截图中 78% 的红柱（规则判为红的日子里有 68% 确实是红），绿柱约 62%。
- 在 PPT 自己的这些「赢家」上按规则交易，平均每个案例能拿到 +112%；但 21 个里有 7 个根本买不进
  （信号出现后的第二天直接一字涨停开盘），其中就包括宣传最夸张的 +659% 和 +386% 两个。
- 换成**所有股票**而不是挑好的赢家（2,189 只中证 1000 / 中证 2000 成分股，2025-01 至 2026-03），
  同一规则每月出现约 640 次信号，胜率 32%，平均每笔亏 0.4%。按 PPT 的仓位规则（每只三成仓、最多 3 只）
  做组合，总收益 **-52%**，同期中证 1000 指数 **+33%**。
- 你推测的「人工选股：先找热门行业，再选行业龙头」，以及我们额外提出的三个改进（市场情绪择时、放宽离场、
  回踩再买），都做了样本外检验：有的在 2025 年 1-8 月看起来不错，**但没有一个在 2025-09 至 2026-03 站得住**，
  两个时间段里被动持有指数都跑赢了所有方案。
- 第二个推测「按新闻和题材挑股」用 317,390 条公司公告和 330 个概念板块做了检验：有公告催化或处在热门概念里的信号，
  同样在样本外失效。PPT 的 21 个牛股里只有 4 个在启动前有公司层面的催化，其余都是被行业或政策新闻带起来的，
  这些消息不在任何公告里。
- 第三个推测「买全新题材的第一个涨停」，可用的历史只有 4 个月（44 个事件）：看不出优势，而第二天早上追任何涨停股都跑输指数。
  家庭节点上已经开始每天存档新闻和题材数据，以后才能把这个思路检验清楚。
- PPT 第 25、35 页的收益测算从它自己的前提推不出来，而且默认每一笔都赚 30%。

## 2. 从截图里把信号「反推」出来

`extract_slide_signals.py` 直接从 pptx 里读出每张案例截图，在 K 线区域拟合一个等距的 N 根柱子网格
（每张图上都印着「周期数 N 个」），再到下方副图里逐根判断是红柱（+100）还是绿柱（-100）。
22 张图中，图表起止日期之间的交易日数都正好等于 N，所以每一根柱子都能精确对应到具体日期。
结果存为 `slide_signals.csv`：共 1,590 个交易日，其中红柱 261 个、绿柱 234 个。

这些标注日子的特征（22 张图合计）：

| | 红柱日 | 绿柱日 | 其他日子 |
|---|---|---|---|
| 收盘价在 MA20 上方 | 100% | 79% | 55% |
| 多头排列 MA5 > MA10 > MA20 | 97% | 57% | 31% |
| 当天涨停 | 43% | 4% | 6% |
| 当日涨跌幅中位数 | +9.5% | -1.1% | +0.2% |

也就是说：红柱 = 股票处在又陡又整齐的上涨里（经常是连续涨停）；绿柱 = 上涨后第一次走弱，但价格还在高位。
在这些标注上搜索规则（用「留一案例交叉验证」检查过：每次用 21 张图选规则、在剩下 1 张上打分，红柱 F1 为 0.71，
说明规则不是对这 22 张图死记硬背出来的），得到：

| 信号 | 规则 | 精确率 | 召回率 |
|---|---|---|---|
| 红柱（主升浪进行中） | MA5 > MA10 > MA20，且 3 日涨幅 ≥ 10% | 68% | 78% |
| 绿柱（主升浪结束） | 前 15 根 K 线内出现过红柱、今天不是红柱、收盘跌破 MA5 | 61% | 63% |

（精确率：规则判为红的日子里，真正是红的比例；召回率：真正的红柱日里，规则找出来的比例；F1 是两者的综合。）

再加一个强度条件几乎没有提升（F1 0.724 对 0.726），所以保留最简单的规则。这只是对一个闭源公式的**近似**，
不是原公式。所有比较都加了 1e-9 的相对容差，保证「正好相等」（例如价格横盘时 MA10 = MA20）的情况在
任何 pandas 版本下结论一致。

### 3.3 PPT 的收益测算（第 25、35 页）

| PPT 的前提 | 实际推出来的结果 |
|---|---|
| 三成仓位 × 单只赚 30% | 每笔让总资金涨 9% |
| 一年做 12 笔 | 单利 +108%，复利 +181% |
| 每月 1-2 笔（一年 24 笔） | 复利 +691% |
| 「满仓年复利约 1.44 倍」 | 只需每笔 +3.1%；真按满仓、每笔 +30% 复利 12 次是 +2,230% |
| 「12 只累计收益约 244%」 | 需要每笔让总资金涨 10.8%（三成仓时单只要赚 36%） |

（单利：每次赚的钱不再投入；复利：赚的钱继续投入，利滚利。）

PPT 的几个数字都推不出来，而且全部假设每一笔都赚 30%、没有亏损、没有成本。在第 4 节的全市场测量里，
只有 2.2% 的信号能做到 +30%。

## 5. 人工选股能救回来吗？（热门行业 + 行业龙头）

据说这个团队会人工选股，最自然的推测是「先找准热门行业，再选其中的龙头」。`sector_study.py` 把它写成规则，
**阈值在看结果之前就定死**（不调参），再加上我们自己的三个想法，分别在两段时间上检验：
样本内 2025-01 至 2025-08，样本外 2025-09 至 2026-03。行业用申万二级行业（`industry_sw.csv`，5,577 只股票，
今天从新浪抓的快照；股票池里有 103 个行业至少有 5 只成员股）。申万行业是国内最常用的行业分类，二级约 130 个行业。

- 热门行业：股票所在行业的成员 5 日涨幅中位数排在全部行业前 5，且当天该行业至少有 2 只股票是红柱。
- 行业龙头：在本行业当天的红柱股票里，5 日涨幅最高（且该行业至少 2 只红柱）。
- 情绪择时（我们的想法）：只在「现在追涨赚钱」时出手，即前一批信号股第二天「开盘到收盘」的收益，3 天平均为正。
- MA10 离场（我们的想法）：收盘跌破 MA10 才卖，而不是跌破 MA5，让龙头的利润多跑一会儿。
- 热门回踩（我们的想法，运行前就登记好）：不在信号当天追，而是在之后 5 天内第一次回落到 MA5 附近、且多头排列还在时买入。
  先按 MA5 离场跑了一次；由于回踩买入点本身就在 MA5 附近，MA5 离场会立刻触发，所以又按 MA10 离场跑了一次。

PPT 自己的 2025 年案例，在它们第一次出现红柱的那天是什么状态（10 个案例，同行业对比用本地股票池）：

- 10 个里有 7 个是本行业 5 日涨幅第一（个股意义上的「龙头」）。
- 只有 1 个所在行业排进前 5，3 个排进前 10（共 126 个行业）；大多数所在行业排在第 19-54 名。

结论：

- 这些过滤大幅减少了交易次数，有的在样本内看起来能赚钱，最好的是「热门 + 龙头 + MA10 离场」（+54%）。
  但**每一个在样本外都亏钱，而且两段时间都跑输指数**。只在「选它的那段数据」上有效的规则，是过拟合，不是真本事。
- PPT 里的牛股大多是「独行侠」：在一个平静的行业里自己涨得最猛，而不是热门行业里的龙头。
  这说明驱动它们的是个股消息或题材概念，而这是只看价格和行业分类看不到的。
- 就目前的证据，比追这些信号更好的办法就是简单持有指数。下一小节检验剩下最显然的思路：个股公告和概念板块。

### 5.1 第二个推测：按新闻和题材挑股

如果团队是按消息或题材挑股，那么「有公告催化」或「所属概念正在走强」的红柱信号，应该比其他信号表现更好。
`fetch_catalysts.py` 下载数据，`catalyst_study.py` 用和上面完全相同的规则检验（样本内 / 样本外划分、成本、仓位）。

数据（除概念归属外，全部按时点使用，不偷看未来）：

- 公告：2,032 只信号股和案例股在巨潮资讯（交易所官方信息披露网站）上的全部公告标题，共 317,390 条。
  第 t 天的信号只能看到日期在 t 及以前、7 个自然日以内的公告；成交在 t+1 日开盘。
- 「催化」（让股票有理由上涨的消息）= 标题命中以下任一类：控制权变更（含协议转让股份、要约收购）、
  新的重组 / 购买资产预案、销售合同或中标、新的回购或增持计划、新的股权激励草案、药品 / 产品获批，
  或业绩预告为「预增」/「扭亏」（取自东方财富业绩预告表，因为预增还是预减不写在标题里）。
  同时命中负面消息（拟减持、未回复的问询函、立案、终止交易等）的标题不算。「股票交易异常波动公告」
  （股价连续大涨大跌后交易所要求发的公告）单独统计：它是价格的结果，不是原因。
  这些规则是人工抽样检查过的，没有量化准确率；下一步应换成 LLM 打标签。
- 概念：每只股票在东方财富的题材概念标签（370 个概念，其中 330 个在股票池里至少有 8 只成员股）。
  第 t 天的概念热度用成员股的本地行情计算：5 日涨幅中位数（在所有概念里排名）和当天涨停家数。
  概念标签是今天的快照，股票在行情之后才被归入的概念也会被算到过去，这一点**偏向支持**这个推测。
- 东方财富的行情接口对本机网络做了批量请求封锁，所以概念热度改用本地行情计算，而不是东方财富的概念指数。

各方案的阈值在运行前固定：有催化 / 无催化 / 各类催化单独看；「热门概念」= 所属概念之一当天 5 日涨幅排进前 10；
「题材扎堆」= 当天至少还有 2 只同概念股票也出了首个红柱；「涨停潮」= 所属概念之一当天至少还有 3 只成员涨停。

用仓库里的 `quant/ml/llm/` 层打标签）；这部分尚未实现。

### 5.2 第三个推测：买「全新题材」的第一个涨停

最接近「新闻映射到题材」、又有一定历史的数据，是同花顺的涨停池：每只涨停股，同花顺编辑当天都会写一条涨停原因，
例如「液冷算力+特种油升级+三季报增长」。网站只保留大约一年；`scripts/news_archive.py` 已把这一年
（2025-10-09 至 2026-10-23，17,133 条）存进 `data/news/ths_limit_up/`，之后由家庭节点每天继续存档。
`theme_study.py` 在它和本地行情重叠的 2025-11-06 至 2026-03-12（去掉前 20 天预热后共 83 个交易日）上检验，定义事先固定：

- 标签 = 涨停原因按「+」拆开；「新题材」= 某个标签今天至少有 2 只涨停、而前 20 个交易日一次都没出现；
  其中首次封板最早的是「龙头」，其余是「跟风」；
- 「热门题材成员」= 前 20 天出现过、今天至少有 3 只涨停的标签；「孤立涨停」= 当天没有别的涨停股和它共享任何标签；
- 次日开盘买入（一字涨停开盘买不进），1 / 5 / 10 天后收盘卖出，成本同前；t 值按每天的平均收益计算，热闹的日子不会被重复计数。

- 第二天早上追涨停股，各个持有期都亏钱、都跑输指数；孤立涨停最差。

  而这笔订单在那天之前没有出现在任何公司公告里，所以消息来自新闻或互动问答。

结论：目前还没有任何方法跑赢指数。新闻存档是公平检验的前提：等存档积累 6-12 个月后，重新跑这项研究和打了新闻标签的版本。

## 6. 聚宽脚本

`jq_strong_dragon.py` 是一个单文件，整份粘贴进聚宽策略即可。建议回测设置：日频、100 万资金，先跑一年
（每天要读约 5,000 只股票的 45 根 K 线）。

- 每天 09:30 在 `trade_at_open` 里用**昨天收盘**的数据算信号，**今天开盘**下单，避免用到未来数据。
- 先卖：出绿柱，或昨收 ≤ 成本 × (1 - 8%)；开盘跌停时卖不出，顺延到下一天。
- 再买：新红柱，非 ST，上市满 60 天，只做沪深，近 20 日平均成交额 ≥ 5,000 万元，按 3 日涨幅排序；
  开盘涨停则跳过；每只占总资金 30%，最多 3 只。
- 所有参数都是文件顶部的常量。

聚宽用的是老版本 pandas（低于 0.24）。第一版在聚宽上报错
`TypeError: shift() got an unexpected keyword argument 'fill_value'`；现在的脚本已经不再使用
`shift(fill_value=)`、`notna()/isna()` 以及对布尔值做滚动窗口这些新写法。

本地做过的验证（没法直接连聚宽）：

- 在 Python 3.6.8 + pandas 0.23.4 环境里，旧写法复现了你遇到的同一个报错，新脚本能正常运行；
  在一个 400 只股票 × 293 天、人为插入停牌缺口的面板上，信号与 pandas 3 的结果逐值一致，0 处差异。
- `compute_signals` 与研究代码 `sd_signals.add_indicator` 在本地股票池全部 638,469 个股票日上逐值一致，0 处差异。
- 用模拟的聚宽 API 跑了 60 个交易日：买入、开盘涨停跳过、绿柱卖出、止损都正常，pandas 0.23.4 和 pandas 3 下的交易完全相同。

聚宽上的任何结果都只当研究用；按 `AGENTS.md` 的约定，这里的东西不进实盘。

5. 运行 `scripts/jq_auto_claim.py`：登录；从「浏览社区文章」任务打开一篇文章读一分钟；点每日签到；
   最后打印签到前后的可用积分和积分明细里最新的几条。

账号密码放在 Gitee Go 的「通用变量」里，变量名 `JQ_USERNAME` 和 `JQ_PASSWORD`，类型选「密文」。
通用变量必须在流水线编辑页里「关联」到这条流水线（关联后 Gitee 会把它写进 YAML 的 `ref_variable:`），才会传进构建；
没关联时，构建里既看不到值也看不到变量名（实测）。YAML 先执行 `set +x`（关掉命令回显），再把这两个变量 export 给脚本，
所以值不会出现在命令回显里。`.env`、GitHub Secrets 和代码里用的也是这两个名字。

点签到按钮会弹出滑块拼图验证（「完成拼图验证」）。按约定**不自动破解**它，因为那等于绕过聚宽的防机器人措施；
脚本会关掉弹窗、在日志里打印 `ACTION REQUIRED: ... check in by hand`，签到需要你在积分页上手动点一下。

在 Gitee 上的实测结果（2026 年 10 月）：

| 检查项 | 结果 |
|---|---|
| Gitee 执行机是否被聚宽地区限制 | 没有，登录页正常打开 |
| Playwright 官方 CDN 下载速度 | 完整版 Chrome（191 MB）5 分钟下到 40% 后停滞，构建被取消 |
| 不配置账号密码时 | 约 2 分钟失败退出（大部分时间花在 pip 安装） |
| 命令回显 | 插件会回显命令，`set +x` 之后 export 那一行不出现在日志里 |
| 构建元数据（`Job params`） | 记录的是 `$JQ_PASSWORD` 这个字面引用，不是密码本身 |
| 通用变量未关联到流水线时 | 不会注入：构建参数和环境变量里都没有 |
| 定时触发（08:05） | 正常触发（触发类型 TIMER） |
| 关联变量后登录 | 成功；每次约 4-6 分钟，大部分时间花在 pip 和浏览器安装 |
| 每日签到 | 被滑块验证拦住（见上） |
| 浏览文章 | 能打开并读完一篇文章；当晚积分明细里没有出现对应积分 |

尚未验证：浏览文章的积分是否稍后入账（积分明细里 2026-09-04 的浏览积分是在签到前几秒入账的，可能要和签到一起发放）。
另外，某一步失败时 Gitee 会跳过「产出暂存」，所以 `output/` 里的调试截图只在成功的构建里保留。

## 10. 术语表

| 术语 | 在本文中的意思 |
|---|---|
| 涨停 / 跌停 | 单日最大涨跌幅：主板 10%，创业板和科创板 20%，北交所 30%，ST 股 5%。 |
| 一字涨停 | 开盘即涨停且全天不打开（开 = 高 = 低 = 收），买单排队几乎成交不了。 |
| 主升浪 | 行情中最陡的一段上涨，常表现为连续涨停。 |
| 均线 MA5 / MA10 / MA20 | 最近 5 / 10 / 20 个交易日的平均收盘价；MA5 > MA10 > MA20 称为多头排列，代表上涨趋势。 |
| 3 日 / 5 日涨幅（ret3、ret5） | 相对 3 / 5 个交易日前收盘价的涨幅。 |
| 新红柱 | 前一天不是红柱、今天变成红柱，是本文的买入信号。 |
| 前复权 | 按分红、送股把历史价格调整一遍，使跨除权日的涨跌幅计算正确。 |
| T+1 | 今天买的股票，下一个交易日才能卖。 |
| 滑点 / 佣金 / 印花税 | 交易成本：成交价比预期差的那一点、券商手续费、卖出时交的 0.05% 税。 |
| 事件研究 | 把每一个信号都当作一笔独立交易，看所有结果的分布。 |
| 胜率 | 赚钱的交易所占比例。 |
| 总收益 / 年化收益 | 整个期间的收益 / 折算成每年的收益。 |
| 最大回撤 | 资金曲线从前高往下最深的一次跌幅。 |
| 夏普比率 | 平均收益除以波动再年化；大于 1 算好，小于 0 表示亏钱。 |
| 精确率 / 召回率 / F1 | 规则判为红的日子里真为红的比例（精确率）；真红柱里被规则找出的比例（召回率）；F1 综合两者。 |
| 留一案例交叉验证 | 用 21 张图选规则、在第 22 张上打分，对每张图轮流做一遍，检查规则是否死记硬背了这些图。 |
| 样本内 / 样本外 | 用一段数据设计规则，用之后没用过的数据检验；只有样本外结果算数。 |
| 过拟合 | 规则只适合选它的那段历史，换一段数据就失效。 |
| 幸存者偏差 | 只研究今天还存在、还在指数里的股票，结果会偏乐观。 |
| 未来函数 / 前视偏差 | 用了决策当时还拿不到的信息；本文用「收盘出信号、次日开盘成交」来避免。 |
| 申万行业（一级 / 二级） | 国内最常用的行业分类；二级约 130 个行业。 |
| 龙头 | 某个题材或行业里最先启动、涨得最猛的股票。 |
| 催化 | 让股票有理由上涨的消息，例如控制权变更、收购、大合同、业绩大增。 |
| 概念板块（题材） | 按「故事」而不是按行业归类的一组股票，例如「人形机器人」「商业航天」；一只股票可以属于很多个概念。 |
| 异常波动公告 | 股价连续几天大涨或大跌后，交易所要求公司发布的公告；它是对价格的反应，不解释上涨原因。 |
| t 值（t-statistic） | 平均收益除以它的标准误；粗略地说，绝对值超过 2 时结果不太可能是运气。 |
| 情绪择时 | 根据市场追涨是否赚钱来决定要不要出手。 |
