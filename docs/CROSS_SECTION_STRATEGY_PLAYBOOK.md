# 截面策略开发手册（恢复版）

## 一、策略类型定义

- 策略类型：截面策略（Cross-Section）
- 核心动作：在同一时点比较股票，买入得分最高的前 N 只。

## 二、因子框架（可直接落地）

## 1) 因子大类

- 动量：近 20 日 / 60 日收益率
- 价值：PE、PB（可扩展 PEV）
- 质量：ROE、毛利率、营收增速
- 风险：波动率、换手率、流动性
- 技术：MA、MACD、RSI、KDJ、成交量趋势等

## 2) 基础打分模板

```text
得分 = 动量 * 0.3 + 价值 * 0.3 + 质量 * 0.3 + 低波动 * 0.1
```

可执行定义示例：

- 价值得分 = `1 / PB`
- 质量得分 = `ROE`
- 动量得分 = `近20日收益率`
- 低波动得分 = `1 / 近20日收益率标准差`

## 三、交易规则参数

- 调仓周期：日 / 周 / 月（截面常用周/月）
- 持仓数量：20 / 30 / 50
- 股票池：全市场 / 沪深300 / 中证500 / 中证1000 / 小微盘
- 过滤：ST、停牌、次新（如上市不足 60 日）

## 四、风险参数（必须）

- 单票最大仓位：5%~10%
- 行业最大仓位：20%~30%
- 止盈止损：固定止损 + 移动止损
- 最大回撤控制：触发后降仓或停止交易

## 五、回测参数与评估指标

## 1) 回测参数

- 年限：建议 >= 5 年（受数据权限时可先 1 年验证）
- 交易成本：
  - 买入 0.03%
  - 卖出 0.13%
- 滑点：建议至少 0.05%~0.1%，小盘压力测试可提升到 0.1%~0.3%

## 2) 核心评估指标

- 年化收益
- 最大回撤
- 夏普比率（经验阈值：>1.5 更稳）
- 胜率
- 盈亏比
- 年度稳定性（样本外一致性）

## 六、最简可跑流程

1. 准备数据接口（JQ/QMT/本地 SQLite）
2. 编写因子计算
3. 编写截面排序打分
4. 编写调仓与交易执行逻辑
5. 回测 + 样本外验证
6. 小资金实盘跟踪（先验证执行质量）

## 七、每周执行样例

1. 每周一获取股票池
2. 剔除 ST、停牌、次新
3. 计算因子：动量、低波、技术趋势
4. 标准化并等权/加权打分
5. 选前 30 名等权持有
6. 下周一再平衡
