# 白马组合收益诊断与改进建议

## 结论先说

当前“本地策略收益明显高于白马组合策略”是合理现象，根因是策略定位不同：

- 本地最优配置偏进攻（中证2000、集中持仓、趋势优先），目标是收益上限；
- `jq_horse` 里的白马攻防偏防守（基本面+温度分层+低频调仓），目标是稳定性。

当前可对照结果：

- 本地全局最优年化约 **101.38%**；
- 模拟 `0.5,0,0.5,0`（小市值+ETF轮动）组合年化约 **38.31%**。

---

## 先说明当前策略结构（重点：小市值与ETF轮动）

## 资金比例含义（严格按顺序）

`g.portfolio_value_proportion = [0.5, 0, 0.5, 0]` 对应：

1. 小市值
2. ETF反弹
3. ETF轮动
4. 白马攻防

也就是：小市值 50%，ETF轮动 50%，ETF反弹/白马攻防关闭。

## 当前“小市值”策略是如何工作的

`jq_horse.py` 中小市值腿的核心特征：

- **选股池**：以中证小盘集合（`399101.XSHE`）起步，再做 ST/停牌/新股等过滤。
- **多版本筛选**：`xsz_version` 有多套逻辑（v1/v2/v3），默认 `v3`。
- **因子倾向**：强调市值、盈利质量（如 ROE/ROA）、部分风控过滤（审计、分红、异常等可选）。
- **仓位与风控**：
  - 固定止损/市场止损/组合止损；
  - 可选 ATR 止损；
  - 可选成本保护止损；
  - 顶背离风控和不买入窗口。
- **调仓风格**：比白马更主动、交易频率更高，收益弹性更强。

## 当前“ETF轮动”策略是如何工作的

ETF轮动腿（策略3）核心流程：

1. ETF池预加载历史数据（提高运行效率）；
2. 五重过滤：
   - 近3日跌幅过滤；
   - 动量评分过滤（加权回归年化收益 × R²）；
   - RSRS + 均线过滤；
   - 成交量异常过滤；
   - RSI过热过滤；
3. 选出第一名ETF，若与当前持仓不同则调仓；
4. 有日内止损开关（按时间点做日内亏损检查）。

这个腿本质是“趋势+风险过滤”的动量系统，和小市值腿相关性较低，组合后往往改善回撤。

## 为什么白马腿通常拖低组合收益

白马（策略4）当前特征：

- 主要基于沪深300池子 + 基本面温度分层；
- 月频调仓；
- 因子权重固定（`roe=10`, `roa=6`）；
- 持仓数较低（默认5只）；
- 同时叠加多重过滤条件。

因此在高波动、风格快速切换阶段，白马腿更容易“稳但慢”，拖累收益峰值。

## 白马改进细节（可落地）

下面按“改动点 -> 修改建议 -> 预期效果 -> 验证方式”给出。

## P0：先做（低风险高收益）

### 1) 修正白马价格上限阈值所用资金比例

- **现状**：`bm_before_market_open` 的价格上限使用了 `portfolio_value_proportion[0]`（小市值腿）。
- **建议**：改为 `portfolio_value_proportion[3]`（白马腿自身比例）。
- **效果**：候选过滤与白马实际资金一致，避免“白马按小市值资金规模过滤”的偏差。
- **验证**：改前改后对比白马腿候选数、成交数、年化和回撤。

### 2) 白马调仓频率：月频 -> 周频

- **现状**：`run_monthly` 导致换仓滞后。
- **建议**：先改为 `run_weekly`（每周一次），不直接上日频。
- **效果**：提高趋势响应速度，通常提升收益并小幅提高换手。
- **验证**：月频 vs 周频 A/B，比较年化、回撤、交易次数。

### 3) 放宽 warm/hot 温度条件一档

- **现状**：过滤偏严，候选池可能过窄。
- **建议**：
  - warm：`pb` 上限和增长阈值放宽；
  - hot：质量阈值放宽但保留现金流约束。
- **效果**：提升可选股票数量，减少“无股可买”或低弹性持仓。
- **验证**：记录每日候选池数量分布 + 收益变化。

## P1：收益增强

### 4) 持股数 `stock_num_2`: 5 -> 8（再测10）

- **建议**：先测 5/8，再测 10。
- **效果**：提高命中率、降低单票噪声；在温和趋势市通常更优。
- **验证**：固定其他参数，仅改变 `stock_num_2`。

### 5) 动量过滤升级为双窗口

- **现状**：白马当前主要是单窗口动量过滤（25日）。
- **建议**：组合 `20日 + 60日` 双窗口（短中期兼顾）。
- **效果**：降低单窗口噪声导致的误判。
- **验证**：单窗口 vs 双窗口在不同温度下分组统计。

### 6) 温度联动权重与持仓数

- **建议**：
  - cold：提高质量权重，降低仓位/持股数；
  - warm：平衡质量与动量；
  - hot：提高动量权重，持股数适当增加。
- **效果**：参数对不同市场状态更自适应。
- **验证**：按温度分层输出收益贡献。

## P2：稳定性增强

### 7) 白马腿加入止盈回撤保护

- **建议**：参考已有动态止损思想，白马腿单独设置回撤止盈。
- **效果**：减少盈利回吐，提升盈亏比。

### 8) 白马腿单腿风险阈值

- **建议**：增加“白马腿最大回撤阈值”，触发后降仓，不全清。
- **效果**：保留参与度同时控制尾部风险。

## 推荐实验顺序（避免归因混乱）

每轮只改一类变量：

1. 资金比例阈值修正（P0-1）
2. 调仓频率（月 -> 周）
3. 过滤强度（严格/中等/宽松）
4. 持股数（5/8/10）
5. 双窗口动量（20+60）
6. 温度联动权重

固定评估指标：

- 年化收益
- 夏普
- 最大回撤
- 交易次数/换手
- 超额收益

---

## 实操建议（你当前目标是收益优先）

- 主收益腿保持：小市值 + ETF轮动（`0.5,0,0.5,0`）；
- 白马腿先独立优化，达到目标后再加入组合（建议先 0.1~0.2）。

这样可以避免白马在未优化完成时拖累总组合。
