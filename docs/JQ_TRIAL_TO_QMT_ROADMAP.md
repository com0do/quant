# JQ 试用期到 QMT 实盘路线图（恢复版）

## 阶段 A：JQ 试用窗口（策略评估期）

目标：在可用时间窗内尽快筛掉无效策略，固化可用参数。

- 数据侧：
  - 拉取 CSI1000 / 小微盘范围的日线 + 基本面 + 因子快照
  - SQLite 断点续传，避免重复消耗额度
- 研究侧：
  - 先跑 baseline
  - 再做 scan-optimize / iterative-optimize
  - 重点观察：超额收益、最大回撤、稳定性

## 阶段 B：过渡期（模拟+小资金）

- 执行层先用 PaperBroker 验证：
  - TWAP/VWAP
  - 超时撤单+追价
  - 风控触发一致性
- 用小资金验证实盘偏差：
  - 滑点
  - 成交率
  - 实时风险响应

## 阶段 C：QMT 正式实盘（持续评估）

- QMT 成为行情+交易主链路。
- 每日把交易与行情增量落地 SQLite：
  - 持仓变化
  - 成交明细
  - 执行偏差
- 周期性复评：
  - 回测+实盘一致性对比
  - 参数是否漂移
  - 是否需要降仓/切换策略

## 关键原则

- 不追求单次最优参数，追求样本外稳定性。
- 不以高胜率为唯一目标，优先控制回撤和执行风险。
- 数据资产持续沉淀，形成策略迭代护城河。
